01
SCOPE OF THIS POLICY

适用范围

本政策适用于「神秘植物园2」——一款面向 Apple Vision Pro（visionOS）的空间探索应用，以及配套的技术支持网站。项目通过凤凰剧情、AR泡泡、植物模型、温室导览、生命地图和主题互动展开体验。

应用内处理、网站访问和主动提交反馈是不同的使用情境，以下分别说明。设备系统、应用商店及平台服务可能按各自政策独立处理信息。

02
INFORMATION IN THE APP

应用内的信息处理

当前版本无需注册或登录账号，不包含第三方广告、统计 SDK 或开发者提供的云同步服务。应用不会通过这些服务上传使用数据。

03
SPATIAL INTERACTION

空间与交互信息

为了呈现空间内容与响应交互，相关空间与手势信息仅由设备在本地处理，不上传给开发者。场景素材在本地播放。具体系统权限以设备显示与当前功能为准。

Apple 说明，眼部输入不会与应用共享；应用如需访问手部结构与动作信息，应先请求权限。若系统显示相关授权提示，你可以自行选择，并在 visionOS 设置中管理权限。使用注视和轻点操作，不等于应用能取得原始眼动数据。

04
THE SUPPORT WEBSITE

支持网站与本地存储

本网站不包含广告或访问统计脚本。页面可以在浏览器本地保存中英文选择，便于下次访问时使用所选语言。语言偏好不用于跨站跟踪。

填写反馈表单时，内容只在当前页面整理。选择前往 GitHub 后，标题及可通过草稿链接传递的内容会交给 GitHub；内容过长时，可以按提示复制再粘贴。仍需你在 GitHub 页面确认提交，才会创建问题。选择“复制信息”时，报告会写入你的剪贴板。

05
THIRD-PARTY SERVICES

托管与第三方反馈渠道

本网站使用 GitHub Pages 托管。GitHub 会为安全目的记录和保存访问者的 IP 地址，即使访问者未登录 GitHub。相关处理适用 GitHub 的隐私政策。

本项目使用 GitHub Issues 接收支持与隐私请求。你主动发布的描述、截图和 GitHub 公开资料可能对公众可见，开发者可用这些信息排查、回应和跟进问题。请勿提供密码、证件号码、精确位置、可识别人员的空间影像或其他敏感资料。

06
YOUR CHOICES

保留、删除与自主选择

本应用不提供开发者侧的云同步。若应用或 visionOS 在设备端保留布局、设置或临时记录，这些内容由设备端管理，可通过实际可用的应用或系统数据管理功能处理；系统备份的保留方式由相应平台及你的设置决定。“重新开始”用于重新进行当前布局，不应视为删除全部应用或系统数据。开发者无法从服务器恢复从未上传的数据。

你可以清除浏览器中保存的网站语言偏好。清理数据时请确认操作范围，避免同时移除同一网站下的其他本地记录。

07
MINORS AND POLICY UPDATES

未成年人及政策变更

未成年人如需提交反馈，建议由监护人协助，且不要在公开渠道披露姓名、学校、照片、联系方式或现实位置。

当应用平台、权限、数据处理或接入的第三方服务发生变化时，本政策会相应更新，并调整本页日期。相关变化会在新功能启用前说明，并在适用时取得必要授权。

08
CONTACT

隐私相关问题

你可以在本项目的 GitHub Issues 中提交隐私相关问题。该渠道公开可见，请只提供理解请求所需的信息，不要填写敏感个人资料。
